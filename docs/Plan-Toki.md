# Toki (พลังใจ / จิตวิญญาณการต่อสู้) + โบนัสสเตตัสจากผล — สเปก (เจ้าของเกม 22 พ.ย. 2026)

> คำว่า "ฮาคิ" ใช้คุยกันเท่านั้น ในเกมใช้คำว่า **Toki** ทั้งหมด (ห้ามมีคำว่า Haki ในเกม/โค้ด)
> ชื่อ 3 สาย (เจ้าของเลือก): **Armament Toki / Observation Toki / Conqueror Toki**
> ⚠️ หมายเหตุ IP: คำ Armament / Observation / Conqueror เป็นคำทั่วไป แต่คู่กับระบบ 3 สายแบบนี้คนจะนึกถึงวันพีซ
> เจ้าของตัดสินใจใช้แล้ว ถ้าวันหลังมีปัญหา เปลี่ยนแค่ชื่อแสดงผล (id ในโค้ดใช้ `armament` / `observation` / `conqueror`)

## 1. โบนัสสเตตัสจากผลปีศาจ ✅ ทำแล้ว v0.25.69

- ดาเมจสกิลผลยังคิดจาก **max(ATK, MATK)** เหมือนเดิม (ผลไม่ได้เป็นแค่ส่วนเสริม บางคนบิลด์สายผลเป็นหลักได้)
- ผลแต่ละผลบวกสเตตัส 2 ตัว (ขึ้นช่อง BONUS ในหน้า Stats) โตตาม Fruit Mastery:
  - ตัวหลัก +1 ทุก 10 Mastery (ปัดขึ้น) สูงสุด **+10**
  - ตัวรอง +1 ทุก 20 Mastery (ปัดขึ้น) สูงสุด **+5**
- Logia ได้เท่าผลอื่น (เจ้าของ: ทะเลแรก Logia เป็นเมตาได้ พอทะเลถัดไปคนมี Armament Toki ก็ตบ Logia ได้)

| ผล | หลัก | รอง |
|---|---|---|
| Bounce | STR | VIT |
| Blaze | INT | DEX |
| Haze | INT | AGI |
| Shield (Ward) | VIT | INT |
| Split | AGI | DEX |
| Slick | AGI | LUK |
| ผลสัตว์ (ทะเล 2) | VIT | AGI หรือ STR ตามสัตว์ |

- เอาเมาส์วางบนตัวเลข BONUS = แสดงแยกที่มา (Gear / Cards / ผล + Mastery / Toki ในอนาคต)

## 2. Toki: ขั้นพื้นฐาน + ขั้นสูง (คุยรอบ 2, 22 พ.ย.; ยังไม่ทำ)

ลำดับเวลา (เจ้าของ): **Conqueror มีได้ตั้งแต่ทะเล 1** (สุ่ม 0.1% ตอนสร้างตัว + Dev มอบ) ·
วิธีได้ Armament / Observation = **ทะเล 2** · การ evo เป็นขั้นสูง = **ทะเล 3** (วิธี evo คิดทีหลัง)

| สาย | ขั้นพื้นฐาน | ขั้นสูง (evo) — ชื่อท่าของเราเอง |
|---|---|---|
| **Armament** | STR + VIT นิดหน่อย, **ตีโดนร่าง Logia** | **Inner Break**: ทุกฮิตมีโอกาส "ทะลุเข้าข้างใน" = นับเป็นคริ + ไม่สนใจ DEF (คล้ายคริ) และ **+LUK** |
| **Observation** | AGI + DEX = FLEE / HIT ขึ้น | **Foresight** (ดูข้อ 2.1) + **+LUK** |
| **Conqueror** | ทุกสเตตัส +, **ออร่าข่ม**: มอนเลเวลต่ำกว่าเรามาก ๆ ไม่กล้าเข้า / ชะงัก / หนี | **Sovereign Coat**: เคลือบร่าง/อาวุธ = ฮิตมีสายฟ้าดำแดงกระจายโดนรอบตัวโดยไม่ต้องแตะ + **+LUK** เพิ่ม |

### 2.1 Foresight (Observation ขั้นสูง): ทำเมคานิกยังไง
ไอเดียเจ้าของ "โจมตีล่วงหน้า / ศัตรูโดนดาเมจล่วงหน้า" แปลงเป็น 2 ส่วน:
1. **เห็นก่อน**: มอนที่จะตีเรา (ตัวไหนก็ได้ ไม่ใช่แค่บอส) ขึ้นแฟลชแดง + เงาท่าตี 0.4 วิ ก่อนตีจริง (เห็นแค่เรา)
2. **สวนก่อน (Counter)**: ถ้าเราตีมอนตัวนั้นภายใน 0.4 วินั้น = **คริแน่นอน + ขัดท่า (ท่าตีมันหายไป)** ขึ้นคำว่า "FORESEEN!"
   - ฝั่งเซิร์ฟเวอร์: เป้าหมายมี Foresight = มอนดีเลย์ท่าตี 0.4 วิ (`windupUntil`) แล้วส่ง FX ให้ผู้เล่นคนนั้น
   - Auto Battle ก็ได้ประโยชน์ (ถ้าจังหวะตีตรงพอดี) แต่คนเล่นมือได้มากกว่า = รางวัลฝีมือ
3. เสริม (ถ้าอยากได้): เก็บ "ชาร์จหลบ" 1 ครั้งทุก 8 วิ = หลบท่าถัดไปอัตโนมัติ (เหมือนไอเดียหลบ 8 ครั้งในเกมอื่น แต่ของเราคืนทีละชาร์จ)

### 2.2 วิธีได้ (ทะเล 2) + ตัวเลขจากสถิติในเกมตอนนี้
สูตรเกมตอนนี้: โอกาสโดน = clamp(80 + HIT มอน − FLEE เรา, 5..95)%; HIT มอน = เลเวล×1.8+25; FLEE เรา = เลเวล + AGI×1.6 (+โบนัส);
มอนตีทุก 1.3–1.9 วิ ตอนฟาร์มจริงโดนตีราว ~19 ครั้ง/นาที (เฉลี่ย 1 ตัวตีครึ่งเวลา)

ตัวอย่างผู้เล่น Lv30 ตีมอน Lv30 (HIT 79):
| บิลด์ | AGI | FLEE | มอนพลาด | พลาด/นาที | 500 พลาด ≈ |
|---|---|---|---|---|---|
| สายหลบ | 60 | 126 | 67% | ~13 | ~40 นาที |
| สมดุล | 30 | 78 | 19% | ~3.6 | ~2.3 ชม. |
| แทงก์ | 10 | 46 | 5% (ขั้นต่ำ) | ~1 | ~8.8 ชม. ❌ |

→ "มิส 500 ครั้ง" ล้วน ๆ ไม่แฟร์กับสายแทงก์ เสนอนับเป็น **"แต้มอ่านจังหวะ" 500 แต้ม: มอนพลาด = 1 แต้ม, โดนตี = 0.2 แต้ม**
(สายหลบ ~40 นาที / สมดุล ~1.1 ชม. / แทงก์ ~1.8 ชม.) Logia ที่ตีทะลุ = ไม่นับ (ไม่ได้อ่านจังหวะ)

| สาย | ขั้นปลดล็อก | หลังปลดล็อก | เวลาโดยประมาณ |
|---|---|---|---|
| Armament | ฆ่ามอน **1,000** ตัว (ตัวไหนก็ได้) | ทุกการฆ่ามีโอกาส **1%** ได้ (เฉลี่ยอีก 100 ตัว) | ฟาร์ม 4–8 ตัว/นาที ≈ 2–4 ชม. + ~20 นาที |
| Observation | **500 แต้มอ่านจังหวะ** | ทุกครั้งที่มอนพลาด **1%** / โดนตี **0.2%** | ≈ 40 นาที–2 ชม. + ~20–60 นาที |
| Conqueror | สุ่มตอนสร้างตัว **0.1%** / Dev มอบ | — | — |

## 3. ยศท็อปเซิร์ฟเวอร์ตอนเบต้า (ไอเดียเจ้าของ)

- ท็อป 4 โจรสลัด, 7 คนรองลงมา, ฝั่งทหารเรือท็อปเป็นพลเรือเอก ฯลฯ ได้ฉายาพิเศษ (+ อาจได้ Conqueror Toki)
- ⚠️ ห้ามใช้ชื่อ "Four Emperors / Yonko", "Seven Warlords / Shichibukai" (ของวันพีซ)
- 7 คน = **Seven Sea Lords** ✅ (เจ้าของเลือก); 4 คน: เจ้าของเสนอ "Four Conquerors" (ไม่แนะนำ: ชนกับ Conqueror Toki
  ท็อป 4 อาจไม่มี Conqueror Toki คนจะงง) → ตัวเลือก "The Four Crowns" (เข้าคู่กับ Sea Lords) / "The Four Sovereigns"
- ฝั่งทหารเรือ "Admiral" / "Vice Admiral" เป็นยศทหารเรือจริง ใช้ได้
- ใช้ระบบ Titles เดิม (`Config/Titles` ladder Special, ให้ด้วย Admin)

## คำถามที่รอเจ้าของ

1. แต้มอ่านจังหวะ (พลาด 1 / โดน 0.2) โอเคไหม หรือเอามิส 500 ล้วน
2. Foresight: เอา "เห็นก่อน + สวนก่อน" อย่างเดียว หรือเพิ่มชาร์จหลบอัตโนมัติด้วย
3. Conqueror ขั้นพื้นฐาน: ทุกสเตตัส +3 หรือ +5; ออร่าข่มมอนที่ต่ำกว่าเรากี่เลเวล (เสนอ 15)
4. ชื่อ 4 คน: The Four Crowns / The Four Sovereigns / อื่น ๆ
