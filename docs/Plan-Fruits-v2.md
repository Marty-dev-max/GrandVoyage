# ผลปีศาจ v2: สเปกสกิล ท่า และเอฟเฟกต์ (เจ้าของเกม 22 พ.ย. 2026)

> เป้าหมาย: ชื่อสกิล = ท่าอนิเมชัน = FX ตรงกัน ทุกท่าดูเป็นสไตล์ voxel/pixel ของเกมเรา
> จำนวนท่าตามระดับผล: Secret 5–6, Mythic 4–5, Legendary 4–5, Epic 4–5, Rare 4 (+ passive แยก ไม่กินช่องฮอตบาร์)
> ⚠️ IP: ห้ามใช้ชื่อท่าวันพีซ (Hiken, Hotarubi, Gomu Gomu no …, Bara Bara …, White Snake, Gear Second ฯลฯ)
> เราทำท่าที่ "ฟีล" ใกล้เคียงได้ แต่ชื่อและหน้าตาเป็นของเราเอง

## ระบบกลางที่ทุกผลใช้ร่วมกัน

| ระบบ | ทำงานยังไง | ใช้กับ |
|---|---|---|
| **Charge-up (ชาร์จ)** | กดปุ่มสกิลค้าง = ท่าง้าง + FX รวมพลังที่มือ (ยิ่งค้างยิ่งแรง สูงสุด ~1.2 วิ = ดาเมจ x1.6) ปล่อย = ยิงไปทางที่เล็ง (ใช้ระบบกดค้างเล็งที่มีอยู่) Auto mode = ชาร์จสั้นสุดอัตโนมัติ | Bounce Pistol/Recoil Cannon, Blaze Fist, Smoke Fist, Split Cannon, Slick Slide |
| **Channel (ค้างไว้กิน SP)** | กดค้าง = คงสกิลไว้ SP ลดเรื่อยๆ ต่อวินาที ปล่อย/ SP หมด = จบ (บางท่าปล่อยแล้วระเบิดออก) | Ward Barrier Wall, Barrier Dome |
| **Space passive** | กด Space ค้างกลางอากาศ/บนพื้น = ความสามารถพิเศษของผล | Blaze บิน, Ward บันไดบาเรีย, Slick ไถลไปข้างหน้า |
| **Logia** | การโจมตีปกติของมอนผ่านตัวไป ไม่โดน ยกเว้นมอนที่มี **Tōki** หรืออาวุธ Seastone (`def.toki = true`; ทะเลแรก = บอสบางตัว เช่น Mist Commodore + มอนถืออาวุธ Seastone) | Blaze, Haze |
| **สะท้อนกระสุน** | โดนยิงจากมอนสายปืน/ระยะไกล = กระสุนเด้งกลับไปโดนคนยิง เราไม่เสียเลือด | Bounce |
| **กันของมีคม** | โดนดาบ/กรงเล็บ/ฟัน = ไม่เข้า (ตัวแยกส่วน) | Split |
| **แขน/ชิ้นส่วนสีผิวผู้เล่น** | แขนยืด, หมัดลอย, ชิ้นส่วนลอย ใช้สีผิวจริงของตัวละคร (อ่านจากบล็อกแขน) เป็นบล็อก voxel | Bounce, Split |

## Bounce Bounce no Mi (Secret) — ยาง

| ช่อง | ชื่อ | ท่า/อนิเมชัน | FX |
|---|---|---|---|
| 1 | **Stretch Pistol** (ชาร์จ) | ง้างแขนไปข้างหลัง (แขนยืดถอยหลัง) → ต่อยตรง | แขนสีผิวยืดเป็นบล็อกต่อกันไปถึงเป้า แล้วดีดกลับ, คลื่นกระแทกตอนโดน |
| 2 | **Bounce Gatling** | ต่อยรัวสองมือ | หมัดยางหลายสิบหมัดเป็นภาพติดตา (afterimage) สีผิว |
| 3 | **Recoil Cannon** (ใหม่ แทน "bazooka", ชาร์จ) | ง้างสองแขนยืดไปข้างหลังไกลๆ → ผลักสองฝ่ามือพร้อมกัน | ฝ่ามือคู่ยืดออก + วงคลื่นใหญ่ ผลักศัตรูกระเด็นไกล |
| 4 | **Balloon Body** | สูดลมพองตัว | ตัวพองกลม (scale) + สะท้อนกระสุนทุกทิศ ระยะเวลา |
| 5 | **Pump Up** (เดิม Gear Up) | ย่อตัว ปั๊มเลือด | ไอน้ำ/ไอร้อนพุ่งจากตัว ผิวแดงขึ้น ATK/ASPD ขึ้น |
| P1 | **Rubber Hide** | passive | โดนยิงจากมอนสายปืน = กระสุนเด้งกลับ |
| P2 | **Slingshot Launch** | passive: คลิกขวาค้าง = เล็งจุด, คลิกซ้ายค้าง = แขนยืดไปจับจุดนั้น, ปล่อยคลิกซ้าย = ดีดตัวพุ่งไปตามแขน | แขนสีผิวสองข้างยืดไปจับ แล้วดีดตัว |
