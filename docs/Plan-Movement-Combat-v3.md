## 1. อาวุธอิสระ คลาสมีความสามารถเฉพาะตัว (ข้อเสนอเดิม ถูกแทนแล้ว)

**แนวคิด: "อาวุธ = สู้ยังไง, คลาส = เราเป็นใคร"**

| ชั้น | คุมอะไร | ตัวอย่าง |
|---|---|---|
| **อาวุธ** (ใครก็ใช้ได้ทุกแบบ) | คอมโบ M1, สไตล์ Block/Parry, ระยะ, ความเร็ว, "Weapon Arts" 3-4 ท่า | Katana: ฟันเร็ว ช่อง parry กว้าง / ค้อน: ช้า ทุบการ์ดแตก / หมัด: เร็วสุด สั้น / ปืน: ไกล ใช้กระสุน |
| **คลาส** (เลือกที่ Job Master) | พาสซีฟ + 3-4 ความสามารถที่ไม่ผูกกับอาวุธ หน้าที่ของตัวเองบนเรือและบนเกาะ | Doctor รักษา/ชุบ, Shipwright ซ่อมเรือ/สร้างกำแพง, Navigator เรือเร็ว/ลม, Sea Cook บัฟอาหาร |
| **อาวุธประจำคลาส** (สะพานเชื่อม) | ใช้อาวุธของคลาสตัวเองได้โบนัส (เช่น ดาเมจ +10% + ท่าปิดพิเศษ) | Swordsman + Katana = สวนกลับจาก parry แรงขึ้น / Brawler + หมัด = จับทุ่มท้ายคอมโบ |

ข้อดี:
- ดาบ/อาวุธที่ดรอปมีค่ากับทุกคน (บันไดดาบใน Plan-Weapons-v2 ใช้ได้ทุกคลาส ไม่ใช่แค่ Swordsman)
- บิลด์หลากหลาย: Doctor ถือดาบ, Navigator ถือค้อน ได้ฟีลโลกโจรสลัดมากขึ้น
- ระบบรองรับไปครึ่งทางแล้ว: Skill Set (v0.25.71) แยก Class / Fruit / Basic อยู่แล้ว และเคยวางไว้ว่า "Set 3 จะเป็น weapon arts"

ที่ต้องแก้ (ต้นทุนจริง):
- Brawler / Swordsman / Sea Cook / Sharpshooter ตอนนี้ "คลาส = อาวุธ" ต้องหาเอกลักษณ์ใหม่ที่ไม่ใช่อาวุธ (ข้อเสนอในข้อ 2) ไม่งั้นคลาสจะไม่มีความหมาย
- สกิลคลาสตอนนี้เป็นท่าอาวุธ (Flying Slash, Jab Rush...) → ท่าที่เป็นอาวุธย้ายไป Weapon Arts (Set 3), Set คลาสเหลือแต่ความสามารถเฉพาะตัว
- บาลานซ์: สเตตัสจาก `build` ของคลาส vs สเตตัสหลักของอาวุธ (Katana DEX/STR, Baton INT, ค้อน STR, ปืน DEX)
- เซฟ: ผู้เล่นเก่าเก็บอาวุธ+สกิลไว้ สกิลที่ย้ายไป Weapon Arts เปลี่ยนชื่อผ่าน DataService RENAMED
- InventoryService: เอาเช็ค "ไม่ใช่คลาสคุณ" ตอนใส่อาวุธออก; WeaponInfo.ClassWeapon กลายเป็น "อาวุธประจำคลาส"

## 3. แกนการต่อสู้ (C1-C5, C7)

- **Block (C2)**: กดค้าง = ดาเมจจากด้านหน้า x0.3, เกจ "การ์ด" ขึ้นเมื่อโดนตี เต็ม = การ์ดแตก (มึน 1.2 วิ) อาวุธหนัก (ค้อน) ทำให้เต็มเร็วกว่า
- **Parry (C3)**: กด Block ในช่วง 0.2 วิก่อนโดน (ช่องกว้างแคบตามอาวุธ) = ไม่โดนดาเมจ ศัตรูชะงัก 1 วิ + แฟลชแดง + เสียง ใช้กับมอนได้ (เรามีจังหวะ strike + Telegraph อยู่แล้ว)
- **หลบ (C4)**: Q แดช 4 ทิศ (S9) + อมตะ 0.15 วิแรก คูลดาวน์เท่าเดิม
- **ตีหนัก / ตีลอย (C7)**: ตีชาร์จ กระเด็นไป/ลอยขึ้น (มี MS.Knockback แล้ว) + บล็อกแตก + hit stop
- **คอมโบ C1**: M1 4-5 จังหวะต่ออาวุธ (มี 4 แล้ว) + ท่าปิดแบบอื่นตอนกดทิศ/กระโดด
- **C5**: Katana (ดาบเล่มเดียว) กับ Dual Katana (ดาบคู่) เป็นอาวุธ 2 ประเภทแยกกัน แต่ละแบบมีคอมโบ ท่ายืน และ Weapon Arts ของตัวเอง

## 4. การเคลื่อนไหว (ทั้งหมดเป็นอนิเมชันจริงของ Roblox: AnimClips -> build_anims -> อัปโหลด)

- **ชุดท่าเดินของเราเอง** (M1-M3): ยืน / เดิน / วิ่ง / วิ่งเร็ว / กระโดด / ตก / ลงพื้น แทนชุดของ Roblox; เอียงตามความเร็วหันและความเร็ว, ออกตัววิ่งมีฝุ่น
- **พาร์คัวร์** (S1-S7, S10): เรย์คาสต์หน้า/ข้างตัว; ปีน/วิ่งกำแพงจำกัดด้วย **สตามินา** (ไม่งั้นปีนได้ทุกหน้าผา ทุกกำแพง Red Line...) เซิร์ฟเวอร์เช็คความเร็ว/ตำแหน่ง (กันวาร์ป)
- **ตกที่สูง** (M7, M8, S10): ดาเมจเริ่มเมื่อสูงเกินค่าหนึ่ง, ม้วนตัวตอนลงพื้นทันจังหวะ (หรือตอนวิ่งเร็ว) ลดดาเมจ, สูงมาก = ragdoll กลิ้ง (ใช้ของ knockdown)
- **บันได** (M5): คลิปเดินบันได + IK เท้า (IKControl ของ Roblox) หรือแค่ก้าวสั้นลง: ต้องลองใน Studio ก่อน
- **ขอบจอตอนโดน** (M6): Gradient แดงบางๆ จากขอบจอ จางใน 0.4 วิ โดนแรงยิ่งชัดขึ้น
