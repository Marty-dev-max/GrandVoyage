# แผนปรับทะเลแรกใหม่ (Azure East): ผังเกาะ + การเดินเรือ + เอกลักษณ์แต่ละเกาะ

> สถานะ: แผน 20 พ.ย. 2026 รอคอนเซปต์อาร์ตของแต่ละเกาะจากเจ้าของเกม (ส่งมาทีละเกาะได้ ทำตามลำดับด้านล่าง)
> Daybreak ทำใหม่ไปแล้วใน v0.22 (ใช้เป็นมาตรฐานคุณภาพของเกาะอื่น)

## 1. ปัญหาตอนนี้

- เกาะ 2–7 สร้างจากโค้ดสุ่มชุดเดียวกัน → หน้าตาคล้ายกันหมด ไม่มีจุดจำ
- เกาะเรียงเป็นเส้นตรงทุก 1,800 สตั๊ด → แล่นตรงไปเรื่อยๆ ไม่มีการเลือกเส้นทาง ไม่ต้องใช้ทักษะเดินเรือ
- คลาส Navigator แทบไม่มีบทบาทตอนอยู่บนเรือ

## 2. ผังทะเลใหม่: ไม่เรียงเป็นเส้น

```
              (เหนือ)  ~~~~~ CALM BELT (ทะเลไร้ลม มีสัตว์ทะเลยักษ์) ~~~~~
     Honeyslope ·                         · Mikan Isles
            \          · เกาะลับ ?           /
 Daybreak ── Conch Bay ── Marmalade      Barracuda ── Epilogue ── CRIMSON WALL
            /                    \        /
     เกาะเล็ก/ซากเรือ        · เกาะลับ ?   (ทางแยก)
              (ใต้)   ~~~~~ CALM BELT ~~~~~
```

- เกาะกระจายเป็นวงและแยกเป็น 2–3 เส้นทาง ระหว่างทางมี **เกาะเล็ก / ซากเรือ / หินโผล่ / แนวปะการัง** ให้แวะ
- **Calm Belt คงไว้** สองฝั่งเหนือ-ใต้ เข้าไปแล้วลมหยุด มีสัตว์ทะเลยักษ์ (มีอยู่แล้วในเกม: Doldrums)
- ระยะระหว่างเกาะสั้นลงเล็กน้อย แต่ต้องเลี้ยว หลบหิน และเลือกเส้นทาง

## 3. เรื่องราวการเดินเรือ: แผนที่เปิดทาง

- ชนะบอสแต่ละเกาะ → ได้ **"แผนที่ชิ้นต่อไป" (Sea Chart)** ระบบเข็มทิศ (`Sea Compass` มีอยู่แล้ว) ชี้ไปเกาะถัดไป
- **ชนะบอส Conch Bay (กัปตันขวาน)** → ได้ **"แผนที่ทะเลใหญ่" (Grand Current Chart)** ฉีกเป็น 5 ชิ้น
  แต่ละชิ้นอยู่กับบอสเกาะถัดไป ครบ 5 ชิ้นแล้วเข็มทิศชี้ไปยัง **Crimson Wall** ทางเข้าทะเลที่ 2
- ระหว่างตามเข็มทิศจะเจอเกาะอื่นตามเส้นทาง (เกาะลับไม่อยู่ในแผนที่ ต้องสังเกตเอง เช่น เห็นนกบินวน แสงไฟกลางคืน)

> ⚠️ ชื่อในเกมใช้ชื่อของเราเอง (Conch Bay, Crimson Wall, Grand Current, Calm Belt) ห้ามใช้ Shells Town / Grand Line / Red Line

## 4. Navigator: ทำให้ "ต้องมี" บนเรือ

| ความสามารถ | ทำอะไร |
|---|---|
| **อ่านลม** | เห็นลูกศรลมจริงบนทะเล + พยากรณ์พายุล่วงหน้า 30 วินาที (คนอื่นเห็นแค่ลมตอนนี้) |
| **ทางลัดกระแสน้ำ** | เห็น "สายน้ำเร็ว" บนทะเล (เส้นเรืองแสง) เข้าไปแล้วเรือเร็วขึ้น 40% |
| **ฝ่าพายุ / Calm Belt** | เรือที่มี Navigator ในลูกเรือแล่นใน Calm Belt ได้ช้าๆ (คนอื่นลอยนิ่ง) |
| **เข็มทิศสำรวจ** | เจอเกาะลับและซากเรือมีสมบัติ (ไอคอนเฉพาะ Navigator) |
| **Tailwind** (สกิลเดิม) | เรือทั้งลำเร็วขึ้น ใช้กับเรือของเพื่อนในปาร์ตี้ได้ |

## 5. อัปเกรดระบบสร้างเรือ (ทำหลังผังทะเล)

- เลือก **"ตัวเรือสำเร็จรูป"** ก่อน (Dinghy / Sloop / Galleon) แล้วค่อยแต่ง → ไม่ต้องวางบล็อกทีละก้อนตั้งแต่ศูนย์
- ช่องติดตั้ง (slot) บนเรือ: ปืนใหญ่ / ใบเรือ / หัวเรือ / ธง / ห้องเก็บของ → ลากชิ้นส่วนใส่ช่อง
- ดูตัวอย่างเรือ 3D หมุนได้ + ค่าความเร็ว / HP / ปืนใหญ่ เปลี่ยนทันทีที่ใส่ชิ้นส่วน
- สีและลายใบเรือ (คอสเมติก)

## 6. เอกลักษณ์ของแต่ละเกาะ (รอคอนเซปต์อาร์ต)

| เกาะ | Lv | ตอนนี้ | ไอเดียเอกลักษณ์ (เปลี่ยนตามคอนเซปต์อาร์ตได้) |
|---|---|---|---|
| Daybreak | 1–10 | ✅ ทำใหม่แล้ว | หมู่บ้านในป่า ท่าเรือ 3 ท่า |
| Conch Bay | 10–20 | เมืองทหารเรือทั่วไป | ฐานทัพบนหอยสังข์ยักษ์ กำแพงหิน ลานฝึก ท่าเรือรบ |
| Marmalade Town | 20–30 | เมืองทั่วไป | เมืองละครสัตว์ เต็นท์ลายทาง ไฟประดับ ชิงช้าสวรรค์ |
| Honeyslope Village | 30–40 | เมืองทั่วไป | หมู่บ้านบนเนินลาดชัน ไร่ผึ้ง/น้ำผึ้ง ทางขึ้นเขาคดเคี้ยว |
| Barracuda Bistro | 40–50 | เกาะ + เรือ | ภัตตาคารลอยน้ำรูปปลา สะพานแขวนเชื่อมเกาะ |
| Mikan Isles | 50–60 | เมืองทั่วไป | หมู่เกาะสวนส้ม หมู่บ้านใต้ร่มส้ม ปะการัง |
| Epilogue Town | 60–70 | เมืองทั่วไป | เมืองสุดท้ายก่อนทะเลใหญ่ ลานประหาร/หอนาฬิกา ฝนตกตลอด |
| Crimson Wall | 70 | หน้าผาแดง | กำแพงหินแดงสูงเสียดฟ้า บันไดน้ำไหลขึ้น |

**ลำดับทำ:** ผังทะเลใหม่ + แผนที่ชิ้นส่วน → Conch Bay → Marmalade → ... (เกาะละ 1 เวอร์ชัน ส่งภาพเรนเดอร์ให้ตรวจก่อนทุกครั้ง)

**สิ่งที่อยากได้จากเจ้าของเกมต่อเกาะ:** ภาพคอนเซปต์ 1–3 ภาพ, จุดเด่นที่ต้องมี 3 อย่าง, ตำแหน่ง NPC/บอส/ท่าเรือคร่าวๆ

## 7. ข้อควรระวังทางเทคนิค

- เปลี่ยนผังเกาะ = เปลี่ยนตำแหน่งทุกอย่าง (ท่าเรือ, ป้อม, เส้นทางเรือ NPC, เข็มทิศ) ต้องย้ายเซฟผู้เล่นที่ยืนอยู่กลางทะเลกลับเกาะล่าสุด
- `WorldBuilder.WORLD_VERSION` ต้องขึ้นทุกครั้ง แมปเก่าถูกสร้างใหม่อัตโนมัติ
- Daybreak ใช้ RNG แยก ทำเกาะใหม่แบบเดียวกัน (ไฟล์ layout ของแต่ละเกาะ) ไม่กระทบเกาะอื่น
