# ผังโลกใหม่ (เจ้าของ, 28 พ.ย. 2026)

อ้างอิง: แผนที่โลก 3 รูปที่เจ้าของส่งในแชท (ยึด **รูปที่ 3** = แผนที่ทั้งโลกเป็นหลัก). ใช้แค่ **โครงสร้าง** ของแผนที่
(กำแพงผ่ากลางโลก, แถบทะเลคาดกลาง, ภูเขาน้ำไหลขึ้นตรงจุดตัด, ลอดใต้กำแพงไปโผล่อีกฝั่ง) **ชื่อทุกอย่างเป็นของเราเอง**
ห้ามใช้ชื่อในรูป (East Blue, Red Line, Grand Line, Reverse Mountain, New World, Calm Belt ฯลฯ).

ภาพร่าง: `docs/screenshots/world_map_plan.png` (สร้างด้วย `tools/world_map_plan.py`)

## ทะเล 1 (เกาะที่มีอยู่แล้ว ย้ายที่)
เส้นทางซิกแซกจากขอบตะวันออกไปหาภูเขาทางตะวันตกเฉียงใต้ (แบบเกาะบ้านเกิดพระเอกอยู่ขอบตะวันออกในรูป):
Daybreak (15600,-6200) → Conch Bay (13400,-8000) → Marmalade (11200,-5600) → Honeyslope (9000,-8200) →
Barracuda (6800,-5400) → Mikan (4600,-7800) → Epilogue (2700,-4600) → ปากคลอง Backflow Peak (1800,-3200).
ระยะระหว่างเกาะ ~2,800-3,800 studs (ใกล้เคียงตอนนี้). เกาะเกิด 4 เกาะอยู่ตะวันออกของ Daybreak ติดขอบโลก.
ในโค้ด Daybreak อยู่ (0,0) ต่อไป (หลายระบบถือว่าอย่างนั้น) = ทุกตำแหน่งข้างบนเลื่อน (-15600, +6200).

## ระบบที่ต้องแก้ (ตอนนี้โลกเป็นเส้นตรง x เพิ่มตามเลเวล)
- `Config/Islands` x/z ใหม่, ป้อม Guild War, เกาะเล็ก (buildIslets), พื้นทะเล, แผ่นน้ำ Ocean
- `SeaZones.Get` แบ่งโซนตามพื้นที่ (ทะเล / Doldrums / กำแพง); `SeaZones.Segment` นับตามเส้นทาง ไม่ใช่ตาม x
- `WorldBuilder.buildRedLine` → กำแพงกลาง + ขอบโลก + Backflow Peak ที่จุดตัด; `ShipService` ชนกำแพง/ขอบ, segmentBounds, จุดเกิดเรือ NPC
- `Weather` / `Currents` / `Waves` ขอบเขต, ทิศลม (`Atmos`, `Sailing` ลมพัดไปทางภูเขา)
- หน้าต่าง Map = แผนที่ทั้งโลกแบบภาพร่าง (ทะเล 1 สว่าง ที่เหลือ "???"), เข็มทิศ `Readability`, `WorldCull`
- `WORLD_VERSION` ขึ้น (เกาะทุกเกาะสร้างใหม่ที่จุดใหม่)

## ลำดับ
- **W1** ย้ายทะเล 1 ตามผัง + กำแพง/ขอบ/Doldrums + แผนที่ใหม่ (เล่นได้เหมือนเดิม แค่ผังใหม่)
- **W2** Backflow Peak ที่จุดตัด: คลองไต่ขึ้นจากทะเล 1, ไหลลงเข้าทะเล 2 (ยังล็อก Lv 70 / อัปเดตหน้า)
- **W3** เกาะทะเล 2 · **W4** เมืองใต้ทะเล + ทางลอดใต้กำแพง · **W5** ทะเล 3

## W1 ทำแล้ว (0.1.30-remake)
- ตัวเลขข้างบนใช้ภูเขาเป็นจุดศูนย์กลาง (diagram); ในเกม Daybreak = (0,0) และตัวเลขทั้งหมดอยู่ใน `Shared/Modules/WorldShape`:
  Backflow Peak (-15600, 6200), หน้ากำแพง x -15300, ขอบโลกตะวันออก x 2400, ขอบเหนือ z -3800, Doldrums z 3900-4700,
  แถบ Grand Current z 4700-7700 (ล็อก), ปากคลองที่ตีนภูเขาด้านตะวันออกเฉียงเหนือ
- ทะเล 1 ยังเล็กกว่าในรูป (ราว 17,700 x 7,700 studs): ขยายได้ทีหลังโดยแก้ WorldShape อย่างเดียว
- ภูเขา + คลองไต่ขึ้น (ส่วนแรกของ W2) ทำไปพร้อม W1 แล้ว: ฝั่งลงทะเล 2 ยังไม่มี
