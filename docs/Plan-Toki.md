# Toki (พลังใจ / จิตวิญญาณการต่อสู้) + โบนัสสเตตัสจากผล — สเปก (เจ้าของเกม 22 พ.ย. 2026)

> คำว่า "ฮาคิ" ใช้คุยกันเท่านั้น ในเกมใช้คำว่า **Toki** ทั้งหมด (ห้ามมีคำว่า Haki ในเกม/โค้ด)
> ชื่อ 3 สาย (เจ้าของเลือก): **Armament Toki / Observation Toki / Conqueror Toki**
> ⚠️ หมายเหตุ IP: คำ Armament / Observation / Conqueror เป็นคำทั่วไป แต่คู่กับระบบ 3 สายแบบนี้คนจะนึกถึงวันพีซ
> เจ้าของตัดสินใจใช้แล้ว ถ้าวันหลังมีปัญหา เปลี่ยนแค่ชื่อแสดงผล (id ในโค้ดใช้ `armament` / `observation` / `conqueror`)

## 1. โบนัสสเตตัสจากผลปีศาจ ✅ ทำแล้ว v0.25.69

- ดาเมจสกิลผลยังคิดจาก **max(ATK, MATK)** เหมือนเดิม (ผลไม่ได้เป็นแค่ส่วนเสริม บางคนบิลด์สายผลเป็นหลักได้)
- ผลแต่ละผลบวกสเตตัส 2 ตัว (ขึ้นช่อง BONUS ในหน้า Stats) โตตาม Fruit Mastery:
  - ตัวหลัก +1 ทุก 10 Mastery (ปัดขึ้น) สูงสุด **+10**
  - ตัวรอง +1 ทุก 20 Mastery (ปัดขึ้น) สูงสุด **+5**
- Logia ได้เท่าผลอื่น (เจ้าของ: ทะเลแรก Logia เป็นเมตาได้ พอทะเลถัดไปคนมี Armament Toki ก็ตบ Logia ได้)

| ผล | หลัก | รอง |
|---|---|---|
| Bounce | STR | VIT |
| Blaze | INT | DEX |
| Haze | INT | AGI |
| Shield (Ward) | VIT | INT |
| Split | AGI | DEX |
| Slick | AGI | LUK |
| ผลสัตว์ (ทะเล 2) | VIT | AGI หรือ STR ตามสัตว์ |

- เอาเมาส์วางบนตัวเลข BONUS = แสดงแยกที่มา (Gear / Cards / ผล + Mastery / Toki ในอนาคต)

## 2. Toki (ยังไม่ทำ: รอเจ้าของยืนยันตัวเลขข้างล่าง)

| สาย | ได้มายังไง | โบนัส (ร่าง) | ความสามารถ (ร่าง) |
|---|---|---|---|
| **Armament Toki** | ฝึกกับ NPC ครู + เควส (ปลดล็อกเลเวล 1 ที่ Base Lv.30?) | STR + VIT, +1/+1 ต่อเลเวล Toki สูงสุด Lv10 = +10/+10 | ตีโดนร่าง Logia (ผู้เล่น PvP) เหมือนมอนที่มี `toki`; ท่าเคลือบแขน/อาวุธ = ดาเมจ +% ชั่วคราว |
| **Observation Toki** | ฝึก + เควส | AGI + DEX, +1/+1 ต่อเลเวล สูงสุด +10/+10 | FLEE/HIT ขึ้น; ท่า "อ่านจังหวะ" หลบการโจมตีถัดไป 100% ครั้งเดียว (คูลดาวน์) |
| **Conqueror Toki** | **ผู้ถูกเลือกเท่านั้น**: สุ่มติดตัวตอนสร้างตัวละคร **0.1%** + Dev มอบให้เอง (Admin command) | ทุกสเตตัส +3 (หรือ +5?) ไม่ต้องฝึก | แรงกดดัน: มอนเลเวลต่ำกว่ามาก ๆ ชะงัก/หนี, ท่าพิเศษของคนถูกเลือก |

- Conqueror สุ่มตอนสร้างตัว: แบบเดียวกับเผ่า Cinderwing 0.1% (ต่อสล็อตตัวละคร) ตีสัญลักษณ์บน nameplate ให้คนเห็น
- Dev มอบ: ใช้ตอนเปิดเบต้า มอบให้ท็อปผู้เล่น (คำสั่ง Admin `toki conqueror <player>`)
- Toki ได้ผ่าน Fruit Seastone ไหม / ใช้คู่กับผลได้ไหม: ได้ (Toki เป็นของร่างกาย ไม่ใช่ผล)

## 3. ยศท็อปเซิร์ฟเวอร์ตอนเบต้า (ไอเดียเจ้าของ)

- ท็อป 4 โจรสลัด, 7 คนรองลงมา, ฝั่งทหารเรือท็อปเป็นพลเรือเอก ฯลฯ ได้ฉายาพิเศษ (+ อาจได้ Conqueror Toki)
- ⚠️ ห้ามใช้ชื่อ "Four Emperors / Yonko", "Seven Warlords / Shichibukai" (ของวันพีซ) ต้องตั้งชื่อเอง เช่น
  "The Four Tides" / "Sea Sovereigns" (4 คน), "Seven Sea Lords" (7 คน); ฝั่งทหารเรือ "Admiral" / "Vice Admiral" เป็นยศทหารเรือจริง ใช้ได้
- ใช้ระบบ Titles เดิม (`Config/Titles` ladder Special, ให้ด้วย Admin)

## คำถามที่รอเจ้าของ

1. Armament / Observation ปลดล็อกที่เลเวลเท่าไหร่ และฝึกกับใคร (NPC ครูบนเกาะไหน)
2. Conqueror ให้ทุกสเตตัส +3 หรือ +5
3. ชื่อยศท็อปเซิร์ฟ (4 คน / 7 คน) ที่ชอบ
