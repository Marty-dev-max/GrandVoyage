# แผนกิลด์วอร์ (Guild War) ฉบับคุยกับเจ้าของเกม

> สถานะ: แผน 19 พ.ย. 2026 (ยังไม่ได้สร้าง)
> **ตอนนี้ในเกมมีอะไร:** วอร์ป้อมทะเล 3 ป้อม (Fort Driftwood / Tidebreak / Gullwatch) ทุกวันเสาร์ 13:00 UTC นาน 45 นาที
> ตีหอยสังข์ยักษ์ (Signal Conch) ของป้อมให้แตก กิลด์ที่ตีแตกได้ป้อม คนในกิลด์ได้รางวัลตอนจบ (`GuildWarService`)
> **สิ่งที่เจ้าของเกมอยากได้:** ให้ความรู้สึก "ปกป้องบ้านของกิลด์" + บุกเข้าไปทีละห้องเหมือนดันเจียน + ชนะแล้วได้เข้า **ห้องสมบัติ**

## แนวคิดหลัก: กิลด์วอร์ 2 ขนาด

| | **วอร์เล็ก: Hideout Raid (บุกรังกิลด์)** | **วอร์ใหญ่: Sea Fort Siege (ศึกชิงป้อมทะเล)** |
|---|---|---|
| ความรู้สึก | ป้องกันบ้านตัวเอง / บุกบ้านศัตรูเป็นห้องๆ | ศึกใหญ่ทั้งเซิร์ฟเวอร์ ยึดดินแดน |
| ใครกับใคร | กิลด์ต่อกิลด์ (1v1) | ทุกกิลด์พร้อมกัน |
| เมื่อไหร่ | ประกาศบุกได้ทุกวัน (ช่วงเวลาเปิดวอร์ของกิลด์ที่โดนบุก) | สัปดาห์ละ 1 ครั้ง (เสาร์ มีอยู่แล้ว) |
| นานเท่าไหร่ | 15 นาที | 45 นาที |
| จำนวนคน | ฝั่งละ 3–10 คน | ไม่จำกัด |
| ชนะได้อะไร | เข้า **ห้องสมบัติ** ของกิลด์ที่แพ้ | ได้ **ป้อม** = ภาษีเกาะ + บัฟทั้งกิลด์ + ห้องสมบัติป้อม |

---

## 1. รังกิลด์ (Guild Hideout): บ้านของกิลด์

ทุกกิลด์มี **รังลับ** ของตัวเอง เป็นเกาะเล็กส่วนตัว (เทเลพอร์ตเข้าได้จากโต๊ะ Guild Registrar)
สร้างจากโมดูลห้องสำเร็จรูป ต่อกันเป็นทางเดินแบบดันเจียน:

```
[ท่าเรือรัง] → [ประตูหน้า] → [ลาน] → [ห้องโถง] → [ห้องผู้นำ] → [ห้องสมบัติ]
                  เลือกห้องได้ 2–4 ห้องระหว่างทาง (อัปเกรดเพิ่มห้องได้)
```

**ห้องที่กิลด์เลือกวางได้** (ซื้อและอัปเกรดด้วยเงินกองกลางกิลด์ + วัตถุดิบ):

| ห้อง | ทำอะไร |
|---|---|
| ประตูเหล็ก | มี HP ต้องตีให้พัง (ปืนใหญ่ของผู้บุกตีได้แรงขึ้น) |
| ห้องกับดัก | พื้นหนาม, ลูกตุ้ม, ไฟพ่น: ฝั่งรับเปิด/ปิดได้ |
| ห้องปืนใหญ่ | ป้อมปืนให้ฝั่งรับยิง |
| ห้องผู้พิทักษ์ | NPC ทหารของกิลด์ (เลเวลตามการอัปเกรด) |
| ห้องสัตว์เลี้ยง | สัตว์เลี้ยงของสมาชิกช่วยเฝ้า |
| ห้องฟื้นชีพ | จุดเกิดใหม่ของฝั่งรับ (ผู้บุกยึดได้ = ฝั่งรับเกิดไกลขึ้น) |

**ห้องสมบัติ** (ห้องสุดท้าย) มี 3 อย่าง:
1. **หีบกองกลาง (Vault):** เงิน Beli ที่สมาชิกฝากเข้ากิลด์ + รายได้รายวันของกิลด์
2. **หีบรางวัลรัง:** ของที่ระบบเติมให้ทุกวันตามเลเวลกิลด์ (วัตถุดิบ, การ์ด, ไข่สัตว์เลี้ยง)
3. **ถ้วยรางวัล:** เก็บธงที่ชิงมาจากกิลด์อื่น (โชว์ในรัง ไว้อวด)

## 2. วอร์เล็ก: Hideout Raid (บุกรังกิลด์)

**ขั้นตอน:**
1. ผู้นำกิลด์ (หรือรองผู้นำ) เลือกเป้าหมายจากกระดาน **Bounty Board ของกิลด์** (ระบบแนะนำกิลด์ที่พลังใกล้เคียงกัน)
2. จ่ายค่าประกาศสงคราม (Beli จากกองกลาง) แล้วรอเวลา: บุกได้เฉพาะ **ช่วงเปิดวอร์** ที่กิลด์เป้าหมายตั้งไว้ (เลือกได้ 2 ช่วงต่อวัน ช่วงละ 2 ชั่วโมง) ฝั่งรับจะได้แจ้งเตือนล่วงหน้า 10 นาที
3. เริ่มวอร์: ฝั่งบุกเกิดที่ท่าเรือรัง ฝั่งรับเกิดที่ห้องฟื้นชีพ มีเวลา 15 นาที
4. ฝั่งบุกต้องผ่านทีละห้อง ห้องถัดไปเปิดเมื่อทำเงื่อนไขห้องก่อนหน้าครบ (ตีประตูพัง / ยึดธงกลางห้อง / ฆ่าผู้พิทักษ์)
5. **ชนะ = ถึงห้องสมบัติแล้วตี "หีบสมบัติ" ให้เปิดภายในเวลา** (หีบมี HP ฝั่งรับต้องกันไว้)
6. หมดเวลา = ฝั่งรับชนะ ได้ค่าประกาศสงครามของผู้บุกไปครึ่งหนึ่ง + คะแนนป้องกัน

**ของที่ผู้ชนะได้จากห้องสมบัติ:**
- เงินกองกลางของฝั่งแพ้ **ไม่เกิน 10%** (ส่วนที่เหลือถูกล็อกไว้ ปล้นไม่ได้) และไม่เกินเพดานต่อครั้ง
- หีบรางวัลรังของวันนั้น 1 หีบ (ฝั่งแพ้ยังได้ของวันพรุ่งนี้ตามปกติ)
- **ธงกิลด์** ของฝั่งแพ้ ไปแขวนในห้องถ้วยรางวัล
- คะแนนกิลด์ (ใช้จัดอันดับ + เลเวลกิลด์)

**กันการรังแก (สำคัญมาก ไม่งั้นกิลด์เล็กเลิกเล่น):**
- แพ้แล้วได้ **โล่ 24 ชั่วโมง** ใครบุกไม่ได้
- กิลด์หนึ่งบุกได้วันละ 3 ครั้ง / โดนบุกได้วันละ 2 ครั้ง
- บุกกิลด์ที่พลังต่ำกว่าเรามาก = ได้ของน้อยลงมาก (ระบบลดรางวัลอัตโนมัติ)
- ผู้เล่นใหม่ (เลเวลต่ำกว่า 30) ไม่ต้องเข้าวอร์ ไม่เสียอะไร
- ไม่มีผลกับของในกระเป๋าส่วนตัวของสมาชิกเลย (เสียแค่ของกองกลาง)

## 3. วอร์ใหญ่: Sea Fort Siege (ต่อยอดจากของที่มีอยู่)

ป้อมทะเล 3 ป้อมที่มีอยู่ เปลี่ยนจาก "ตีหอยสังข์อย่างเดียว" เป็นป้อมหลายชั้นแบบเดียวกับรัง แต่ใหญ่กว่า:

```
[ชายหาด: ยกพลขึ้นบกด้วยเรือ] → [กำแพงชั้นนอก] → [ลานป้อม: ธงยึด 3 จุด] → [ป้อมชั้นใน] → [ห้องหอยสังข์ + ห้องสมบัติป้อม]
```

- **ช่วงแรก (เรือ):** ทุกกิลด์ล่องเรือเข้าหาป้อม ปืนใหญ่ป้อมยิงใส่เรือ (ระบบเรือ + ปืนใหญ่ที่มีอยู่แล้ว)
- **ยึดธง 3 จุดในลาน:** ถือธงครบ 2 ใน 3 = ประตูชั้นในเปิด + ได้จุดเกิดใหม่ใกล้ป้อม
- **หอยสังข์ (Signal Conch):** แกนกลางเหมือนเดิม ตีแตก = กิลด์นั้นยึดป้อม (เปลี่ยนเจ้าของได้หลายครั้งระหว่างวอร์)
- **ตอนจบวอร์:** กิลด์ที่ถือป้อมอยู่ได้ป้อมไปทั้งสัปดาห์

**ถือป้อมได้อะไร:**
- **ภาษีเกาะ:** % จากภาษีตลาดของเกาะใกล้ป้อม เข้ากองกลางกิลด์ทุกวัน
- **บัฟทั้งกิลด์ทั้งสัปดาห์:** เช่น EXP +5% / ดรอป +5% / ความเร็วเรือ +5% (แต่ละป้อมให้คนละอย่าง)
- **ห้องสมบัติป้อม:** เปิดได้ 1 ครั้งต่อสัปดาห์ ของดีกว่ารัง (การ์ดหายาก, ชิ้นส่วนเรือพิเศษ, โอกาสได้ผลปีศาจ)
- **ธงกิลด์บนป้อม + ชื่อกิลด์ประกาศทั้งเซิร์ฟเวอร์**

**Pirate vs Marine:** กิลด์ Pirate ได้ป้อมเพิ่มค่าหัว / กิลด์ Marine ได้ป้อมเพิ่ม Merit (ระบบฝ่ายที่มีอยู่แล้ว)

## 4. ฤดูกาลและอันดับ

- ทุก 4 สัปดาห์ = 1 ฤดูกาล นับคะแนนจากทั้งวอร์เล็กและวอร์ใหญ่
- รางวัลจบฤดูกาล: ฉายากิลด์, ธงลายพิเศษ, ของตกแต่งรัง, Gems จำนวนจำกัด (ตามกฎ Gems ที่วางไว้)
- กระดานอันดับกิลด์ที่ Guild Registrar

## 5. ลำดับสร้าง (แนะนำ)

1. **รังกิลด์ + เงินกองกลาง** (ยังไม่มีวอร์): ให้กิลด์มีบ้าน ตกแต่งได้ ฝากเงินได้ ← ทำก่อนเพราะเป็นฐานของทุกอย่าง
2. **วอร์เล็ก (Hideout Raid)** แบบห้องตายตัวก่อน แล้วค่อยเปิดให้เลือกห้องเอง
3. **ปรับวอร์ใหญ่** ให้มีชั้น / ธง 3 จุด / ห้องสมบัติป้อม
4. ฤดูกาล + อันดับ

## 6. คำถามให้เจ้าของเกมตัดสินใจ

1. วอร์เล็กอยากให้ **บุกได้ตลอด (มีช่วงเปิดวอร์)** หรือ **นัดวันเวลาตายตัว** เช่น ทุกวันพุธ / ศุกร์
2. เพดานปล้นกองกลาง 10% โอเคไหม (มากไป = กิลด์เล็กเลิกเล่น, น้อยไป = ไม่ตื่นเต้น)
3. ฝั่งรับต้องออนไลน์ไหม: ถ้าไม่มีใครออนไลน์ ให้ NPC ผู้พิทักษ์สู้แทน (แนะนำ) หรือห้ามบุกตอนไม่มีใครอยู่
4. ห้องสมบัติป้อมควรมีโอกาสได้ **ผลปีศาจ** ไหม (ตอนนี้ผลปีศาจได้จากเรือ NPC, หีบกัปตัน, บอส, ต้นไม้เท่านั้น)
