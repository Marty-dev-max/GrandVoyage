## 1. บันไดระดับ (เทียบสีกับ Rarity ที่มีอยู่)

| ระดับ | สี / ดาว | ในโลกเกม (ชื่อเสนอ) | ได้มาจาก |
|---|---|---|---|
| Common | เทา 1 | ดาบทั่วไป | ร้านค้า |
| Uncommon | เขียว 2 | ดาบตีดี (Keen) | ร้าน / ตีขึ้นจาก Common |
| **Rare** | ฟ้า 3 | **ดาบดังชั้นสอง (ชื่อดูข้อ 1b)**: ดาบมีชื่อ มีเรื่องเล่า | บอส / หีบกัปตัน / ตีขึ้น |
| Epic | ม่วง 4 | ดาบดังที่ปลุกแล้ว (Renowned, Awakened) | ตีขึ้นจาก Rare |
| **Legendary** | ทอง 4 | **ดาบดังชั้นสูงสุด (ชื่อดูข้อ 1b)** | บอสใหญ่ทะเลถัดไป / ตีขึ้น |
| **Mythic** | รุ้ง 5 | **ดาบดำ: เจ้าของหลอมด้วยใจจนใบกลายเป็นสีดำ (ชื่อดูข้อ 1b)** | ตีขึ้นเท่านั้น (ไม่ดรอป) |

- ดาบดัง (Renowned / Sovereign) = ดีไซน์เฉพาะตัว + ชื่อ + พาสซีฟของมันเอง ฐานสเตตัสสูงกว่าดาบทั่วไประดับเดียวกัน
  (เหมือนดาบดังในเรื่อง: ฐานดีอยู่แล้ว เลยเริ่มที่ Rare)
- ตัวเลขเป็นของเรา (ไม่ลอก 50 / 21 / 12)
- ดาบดังแต่ละเล่มมี "ทะเบียน" ในเกม (หน้า Registry): เห็นว่าเล่มไหนมีคนครอบครองแล้วกี่คน, คนแรกที่ได้ถูกจารึกชื่อ

### 1b. ชื่อที่เสนอ (หลังอ่านโครงในวิกิ 23 พ.ย.: ในเรื่องมี 4 ชั้นตามจำนวน + ดาบไม่มีชั้น + ดาบต้องสาป
+ ดาบดำที่เกิดจากการใช้พลังใจผ่านการต่อสู้มามาก + สมุดรายชื่อดาบ + ตระกูลช่างตีดาบหลายรุ่น + ดาบคู่แฝด)

| ระดับ | ชุด A ธีมทะเล (แนะนำ) | ชุด B ธีมดวงดาว | ชุด C ธีมช่างตี |

| Common | Plain Blades | Plain Blades | Plain Blades |
| Uncommon | The Forty Fathoms (40) | The Forty Lanterns (40) | Forge-Marked |
| Rare | **The Twenty Tides (20)** | **The Twenty Stars (20)** | Master-Marked (20) |
| Epic | Tide Blade, Awakened | Star Blade, Awakened | Master-Marked, Awakened |
| Legendary (ทอง) | **The Seven Crowns (7)**: 1 เล่มต่อ 1 ทะเล | **The Seven Polestars (7)** | Sovereign-Marked (7) |
| Mythic (ดำ) | **Abyssforged** | **Eclipsed** | Soul-Tempered |

ของเสริมจากโครงเรื่อง (ชื่อของเรา):
- **The Blade Ledger**: สมุดรายชื่อในเกม เปิดดูได้ว่าเล่มไหนมีคนครอบครองกี่คน ใครได้คนแรก
- **Hungry Blades**: ดาบกระหายเลือด (แทน "ดาบต้องสาป") สเตตัสสูงแต่มีโทษ เช่น ดูด HP เจ้าของ
- **ตระกูลช่างตีดาบ**: ดาบ 3 รุ่นจากตระกูลเดียวกัน (I / II / III) ใส่ครบ 3 เล่มได้โบนัสชุด
- **ดาบแฝด**: 2 เล่มทำคู่กัน ถือคู่ (Twin Blades) ได้พาสซีฟพิเศษ
- อาวุธอื่น (ค้อน กระบอง ปืน) ลงสมุดได้เหมือนกัน

ตัวอย่างชื่อดาบ (สีประจำเล่มต่างกัน ให้คนเลือกตามสีที่ชอบ):

- Twenty Tides (Rare): Gullwing (ขาว), Saltfang (ฟ้าน้ำทะเล), Coralvein (แดง), Moonhook (เงิน ใบโค้งเสี้ยว), Kelpwhisper (เขียว),

- ตอนกลายเป็นดำ: ชื่อเดิม + ฉายา เช่น "Saltfang, Abyssforged" (ใบดำ ขอบเรืองตามสี Toki)

## 2. อาวุธโตไปกับเจ้าของ (ใช้ได้กับทุกประเภท)

1. **Refine +0..+15**: มีอยู่แล้ว (Blacksmith -> Forge)
2. **Bond (ความผูกพัน) Lv 1-50**: ได้ EXP อาวุธจากการสู้ด้วยอาวุธนั้น (ไม่นับ Auto Battle เต็มๆ)
   ทุกเลเวล ATK เพิ่มนิดหน่อย; Lv 10 / 25 / 40 ปลดพาสซีฟ "Echo" ของอาวุธทีละขั้น
3. **Ascend (วิวัฒนาการ)**: Bond เต็มขั้น + Refine ถึงเกณฑ์ + วัตถุดิบ -> Blacksmith ตีขึ้น 1 ระดับ
   (Common -> Uncommon -> Rare -> Epic -> Legendary) ชื่อ + ลุค + ออร่าเปลี่ยน แต่ยังเป็นดาบเล่มเดิมสีเดิมที่ผู้เล่นรัก
   ดาบดังเริ่มสูงกว่าเลยถึงยอดเร็วกว่า ดาบธรรมดาก็ไปถึงทองได้ถ้าเลี้ยงนานพอ
4. **Nightforge (ขั้นสุด, Mythic)**: Legendary + Armament Toki ขั้นสูง + บททดสอบ (บอสเดี่ยว) -> ใบดาบกลายเป็นสีดำถาวร
   ขอบเรืองแสงตามสี Toki ของผู้เล่น (ผูกกับระบบ Toki ทะเล 2 ที่วางไว้แล้ว)
   อาวุธอื่นก็มีขั้นนี้: ค้อนดำ, กระบองดำ, ปืนดำ, หมัด/ขาเป็นเกราะดำ (Brawler / Sea Cook ไม่มีอาวุธ: เป็นผิวดำแบบ Armament)

## 3. ประเภทย่อยต่อสายอาวุธ (ลุค + สเตตัสเอียงต่างกัน, ท่าใช้ชุดเดียวกันของสายนั้นในเฟสแรก)

| สาย | แบบย่อย (form) |
|---|---|
| Sword | Cutlass (สมดุล + ฟันหลายตัว), Katana (สมดุล + คริ), Sabre (เร็ว), Rapier (เร็วมาก + คริสูง ดาเมจต่อทีต่ำ), Broadsword (หนัก), Nodachi (ยาว ระยะไกล ช้า), Twin Blades (ตีรัว) |
| Hammer | Mallet, Sledge, Anchor Hammer (น็อกแรง), War Pick (เจาะเกราะ) |
| Baton | Folding Baton, Tri-Staff, Long Rod (ระยะ), Twin Batons |
| Musket (Sharpshooter) | Flintlock Pistol (เร็ว), Musket (สมดุล), Long Rifle (ไกล คริ), Blunderbuss (กระจาย ใกล้) |
| Powder Pouch | Pouch, Satchel, Censer (กลุ่มควันใหญ่), Flask Belt (ขว้างเร็ว) |
| Fist / Leg Style | ไม่มีอาวุธ: ได้ผ้าพันมือ / สนับแข้งสีต่างๆ + ออร่าหมัด/เท้าตามระดับ |

**สี**: ทุกอาวุธย้อมได้ 2 ส่วน (ใบ/หัว + ด้าม/พัน) ชุดสีเหล็ก: Silver, Blue Steel, Crimson, Jade, Gold, Pearl White,
Violet, Sea Glass + สีด้าม; ย้อมที่ Blacksmith (Doubloons, สีพิเศษใช้ Gems) = เก็บเงินแบบคอสเมติก
ดาบดังมีสีประจำตัว (ย้อมด้ามได้ ใบไม่ได้) Nightforged = ใบดำเสมอ

## 4. บทบาทผู้สร้าง + เพื่อนเพลย์เทส (ฟีล "ผู้ปกครองเงาของโลก" + "สภาผู้เฒ่า")

- **Dev (เจ้าของเกม)**: ตำแหน่ง Secret เช่น "Sovereign of the Hollow Throne" (แทน "Shipwright of Worlds")
  - โหมด **Masked**: ลงไปเล่นเป็นผู้เล่นธรรมดา (ซ่อนตำแหน่ง/ออร่า/เครื่องมือ Dev) ใช้ช่องตัวละครของตัวเองตามปกติ
  - โหมด **Unmasked**: เข้าฉากแบบมีพิธี (ท้องฟ้ามืด, ข้อความทั้งเซิร์ฟ, ออร่า) สั่งอีเวนต์โลกได้
- **เพื่อนเพลย์เทส**: "The Elder Tides" (สภาผู้เฒ่าแห่งกระแสน้ำ) แต่ละคนมีที่นั่งของตัวเอง เช่น
  Elder of Storms / Depths / Iron / Embers / Mist: ตำแหน่ง Legendary + ชุด/ออร่าพิเศษ
  + คำสั่งจำกัด (เปิดอีเวนต์บอส, ประกาศ, มอบตำแหน่ง Special) ไม่มีคำสั่งเสกของ/เงิน (กันเศรษฐกิจพัง)
- ผู้เล่นจะได้เจอพวกเขาในอีเวนต์: บอสที่สภาส่งมา, ภารกิจจากสภา, ค่าหัวที่สภาตั้ง

## 5. ลำดับการทำ (เสนอ)

2. ดาบดังชุดแรก: Renowned 6 เล่มในทะเล 1 (ดรอปบอส/หีบ) ที่เหลือทะเลถัดไป
3. แบบย่อยของทุกสาย (โมเดล voxel + ไอคอน pixel ต่อแบบ x ระดับ)
4. Nightforge หลังระบบ Toki ขั้นสูง (ทะเล 2)
5. บทบาท Dev Masked / Unmasked + สภาผู้เฒ่า (ทำก่อนเพลย์เทส 29 พ.ย. ได้ถ้าเจ้าของต้องการ)
