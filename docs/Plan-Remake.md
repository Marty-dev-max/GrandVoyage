## 4. Field Job Mastery (แทน Job Class) ✅

**ใครก็ทำพื้นฐานได้ คนที่ฝึกจริงเก่งกว่าชัดเจน** (คนเล่นเดี่ยวออกเรือได้ ปาร์ตี้ได้ประโยชน์จากการแบ่งหน้าที่)

1. **พื้นฐาน (ทุกคน)**: ถือค้อนซ่อมเรือ ทำอาหารง่ายๆ ดูเข็มทิศ แต่ประสิทธิภาพธรรมดา
2. **ค่าความชำนาญ (เพิ่มเมื่อทำจริง)**: ซ่อมรูรั่ว → Shipwright, ขับเรือฝ่าพายุ → Navigator, ทำอาหาร → Cook, รักษาเพื่อน → Doctor
   (+ เสนอเพิ่ม: ยิงปืนใหญ่ → Gunner) ปลดพาสซีฟ/แอคทีฟให้เลือกติดตั้ง:

| สาย | Lv 10 | Lv 30 | Master Lv 50 |
|---|---|---|---|
| Shipwright | ซ่อมไวขึ้น 30% ประหยัดไม้ | "Emergency Patch" อุดรูรั่วรอบตัวทันที | เกราะเรือ + ปืนใหญ่ทนขึ้นถาวรตอนอยู่บนเรือ |
| Navigator | เห็นลม/กระแสน้ำ เรือเร็ว +15% | "Weather Sense" เห็นพายุ/น้ำวนล่วงหน้าบนแผนที่ | ฝ่าคลื่นยักษ์ไม่เสียการทรงตัว ลดดาเมจอากาศ |
| Cook | อาหารฟื้น HP/Stamina แรงขึ้น | เมนูบัฟสเตตัสชั่วคราวก่อนสู้บอส | (เสนอ) มื้อเลี้ยงทั้งลำ |
| Doctor | รักษาอาการบาดเจ็บหนักไวขึ้น | "Adrenaline" ชุบเพื่อนที่ล้มทันที + เกราะชั่วคราว | (เสนอ) ชุบจากระยะไกล |

3. **ผูกกับการ์ด Talent**: Mastery ถึงเกณฑ์ → ปลด "Mastery Talents" เข้ากองสุ่ม เช่น Shipwright + มือเปล่า = หมัดทุบโครงสร้าง
   (ตีเรือ/เกราะบอส x2), Cook + เตะ = ลูกเตะเพลิง (ติดไฟ)
4. **Ship Station Assignment**: กัปตันแต่งตั้งตำแหน่งให้ลูกเรือ (ต้นหน / ช่างซ่อม / พลปืน / กุ๊ก) → เปิดบัฟตำแหน่งทั้งลำ
   + แบ่ง EXP Mastery กันตอนออกเรือ (ต่อยอดระบบ "เฉพาะคนที่ HELM ยิงปืนใหญ่ได้" ที่มีอยู่)

- **การ์ด Talent** = ระบบใหม่แยกจากการ์ดมอน (TCG ที่ใส่ช่องอุปกรณ์): เลเวลขึ้น → สุ่มเสนอ 3 ใบ เลือก 1 ใบ เงื่อนไขปลดตามสเตตัส/Mastery
  (ชื่อในเกมต้องไม่ชนกับ "Card" ที่มีอยู่: เสนอเรียก **Talent**)

## 5. ลูปการฟาร์ม (ควบคู่เลเวล)

- **ฟาร์มบอส** = ทาง EXP + ของแรร์ที่ดีที่สุดช่วงกลาง-ท้าย (ต่อยอด BossService, DMG share, drop table ที่มีอยู่)
- **ล่าค่าหัว (Bounty Hunter)**: รับใบประกาศ → วาร์ป/เข็มทิศชี้เป้าผู้เล่นค่าหัวสูง → ล้มเป้า = กล่องรางวัล EXP
  ต้องกันฟาร์มกันเอง (เพื่อนตีกันเอง): ค่าหัวต้องได้มาจากการกระทำจริง, คูลดาวน์ต่อเป้า, เป้าต้องออนไลน์ + ไม่อยู่ในเขตปลอดภัย
- **Sea Events** (ตอนนี้ยังเฉยๆ): ตารางอีเวนต์ทั่วทะเล: กองเรือสินค้าโดนโจรสลัดปล้น, สัตว์ประหลาดทะเลถล่มป้อม, ยิงปืนใหญ่ถล่มค่ายบนเกาะ
  เก็บกล่องสมบัติ + เงิน (เรือ v2 ดีอยู่แล้ว ใช้ได้เลย)
- **Gear & Enchants**: อุปกรณ์ + เอนแชนต์ (ต่อจาก Refine / ใส่การ์ด / Evolve ที่มีอยู่)

## 7. โลกมีชีวิต (AI + ฝ่าย)

- **AI FSM + Utility**: Patrol/Idle (มุมมอง + การได้ยิน) → Alert/ประเมินพลัง → บุก → ตั้งรับ (Block/Parry/ถอย) → ถอยไปหาเพื่อน (HP < 30%)
  → ยอมแพ้/หนี (Morale = 0: กัปตันตาย + ผู้เล่นเก่งกว่ามาก → คุกเข่า ให้ปล้นหรือปล่อย, หรือโดดน้ำหนี)
- **ความทรงจำของฝ่าย**: ช่วยทหารเรือ = ทักทาย/ยิงช่วย, ปล้นหมู่บ้าน = ยามจำหน้า ปิดประตูเมือง
- **ฝ่ายปะทะกันเอง**: เรือสินค้าโดนปล้น, สัตว์ทะเลถล่มป้อม: ผู้เล่นเลือกข้างหรือรอเก็บของ
- **ขวัญกำลังใจกลางทะเล** (แทน Sanity): ติดพายุ/หลงทางนาน = ภาพหลอน เสียการควบคุมชั่วครู่; เสบียง ดนตรี ลูกเรือคุยกัน ช่วยได้

## 8. ผลไม้ต้องสาป v3

- เกิดแบบสุ่มตามจุดลับ / ดรอปบอสสูง; 3 สาย **Body / Element / Beast**
- กินแล้วได้แค่ท่าพื้นฐาน → ใช้จริง/ฝึก ปลดท่าใหม่ (Mastery) → ปลุกพลัง (Awakening) → การ์ด Talent ดัดแปลงท่า (ไฟติดเผา, พุ่งไกลขึ้น)
- ข้อเสีย: ว่ายน้ำไม่ได้ (มีแล้ว), แพ้ Seastone (มีแล้ว), Willpower สูงกว่าต้านได้
- สายไร้ผลไม้: ฝึกวิชาอาวุธ / ศิลปะการต่อสู้ / Toki ได้ลึกกว่า + ใส่อุปกรณ์ต้านผลไม้ได้
- ผลไม้ 6 ลูกเดิม (Bounce, Blaze, Haze, Ward, Split, Slick) + FruitFX เก็บไว้ จัดเข้า 3 สาย

## 9. การรบทางเรือ v3 (ความเสียหายแยกส่วน)

- **ตัวเรือ**: HP หลัก; < 50% รั่ว น้ำเข้า ช้าลง 20%; 0 = จม (มีน้ำเข้า/Bilge Pump แล้ว)
- **ใบเรือ + เสากระโดง**: กำหนดความเร็ว; ลูกโซ่ (Chain Shot) / ฟันไกลใส่ใบ = ช้าลงสูงสุด 70% แต่ไม่จม
- **พวงมาลัย + ปืนใหญ่**: พวงมาลัยพัง = เลี้ยวช้ามาก, ปืนพัง = ยิงไม่ได้ชั่วคราว
- **จุดซ่อม**: รูรั่วสุ่มเกิด (มีน้ำพุ่ง) ต้องถือไม้กระดาน + ค้อนไปกดซ่อม; ใบเรือขาดใช้ม้วนผ้าใบซ่อมที่โคนเสา
- ลูกเรือผู้เล่น: ค่าหัว/ชื่อเสียงนับรวมทั้งกลุ่ม; ลูกเรือ NPC: ความภักดี (เงินเดือน อาหาร อุดมการณ์) → ท่าประสาน หรือหนี/กบฏ
